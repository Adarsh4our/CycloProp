# CycloProp — CFD Study

This folder contains everything needed to run the **5-airfoil 2D RANS CFD comparison** for CycloProp's cycloidal rotor at **Re = 95,000**.

## Folder Structure

```
cfd_study/
├── scripts/
│   ├── gen_airfoil_coords.py      ← Generate NACA .dat coordinate files
│   ├── run_openfoam_sweep.py      ← Automate OpenFOAM (run on Linux)
│   └── integrate_cfd_polars.py   ← Load CFD results → BEMT solver
│
├── airfoil_coords/                ← Generated by gen_airfoil_coords.py
│   ├── naca0009_chord38mm.dat
│   ├── naca0012_chord38mm.dat    ← ★ CycloProp chosen airfoil
│   ├── naca0015_chord38mm.dat
│   ├── naca0018_chord38mm.dat
│   └── naca63012_chord38mm.dat
│
├── openfoam/                      ← OpenFOAM case templates (Linux)
├── ansys/                         ← ANSYS Fluent journal files (IIT lab)
│
└── results/                       ← CFD output CSVs go here
    ├── naca0012_openfoam_Re95k.csv
    ├── naca0012_fluent_Re95k.csv
    └── ...
```

## The 5 Airfoils

| Airfoil | t/c | Why we test it |
|:---|:---:|:---|
| **NACA 0009** | 9% | Structural lower limit — thinnest practical |
| **NACA 0012** ★ | 12% | **CycloProp Rev 3.0 chosen** — validate our design |
| **NACA 0015** | 15% | Original baseline — confirm 0012 is better |
| **NACA 0018** | 18% | Cyclorotor literature candidate (Benedict/Hwang) |
| **NACA 63-012** | 12% | 6-series laminar — potentially 37% lower drag |

All are **symmetric** (zero camber) — required for cyclorotor ±35° cyclic pitch.

## Operating Conditions

| Parameter | Value |
|:---|:---:|
| Blade chord | c = 38 mm |
| Reynolds number | Re = **95,000** |
| Inlet velocity | V = **36.8 m/s** |
| AoA range | **−35° to +35°** (5° steps) |
| Turbulence model | **k-ω SST** |
| Solver | OpenFOAM simpleFoam / ANSYS Fluent |

## Quick Start — Linux (OpenFOAM)

```bash
# 1. Clone the repo (if not already)
git clone https://github.com/Adarsh4our/CycloProp.git
cd CycloProp

# 2. Install OpenFOAM (Ubuntu)
sudo sh -c "wget -O - https://dl.openfoam.com/add-debian-repo.sh | bash"
sudo apt update && sudo apt install openfoam2412 -y
echo "source /usr/lib/openfoam/openfoam2412/etc/bashrc" >> ~/.bashrc
source ~/.bashrc

# 3. Generate airfoil coordinates
python3 cfd_study/scripts/gen_airfoil_coords.py

# 4. Set up OpenFOAM base template
mkdir -p ~/CycloProp_CFD
cp -r $(find /usr/lib/openfoam -name "airFoil2D" -type d | head -1) ~/CycloProp_CFD/base_template

# 5. Run full polar sweep (all 5 airfoils × all angles)
python3 cfd_study/scripts/run_openfoam_sweep.py

# 6. Results saved to ~/CycloProp_CFD/results/
# Copy back to: CycloProp/cfd_study/results/
```

## Quick Start — Windows (ANSYS Fluent @ IIT Ropar)

See full guide: [`ANSYS_Fluent_Guide.md`](../docs/ANSYS_Fluent_Guide.md)

Short version:
1. Open ANSYS Workbench → Fluid Flow (Fluent)
2. Import `airfoil_coords/naca0012_chord38mm.dat` as spline geometry
3. Mesh with inflation layers (first layer 0.005 mm, 20 layers, y⁺ ≈ 1)
4. Fluent: k-ω SST, V_inlet = 36.8 m/s, reference chord = 0.038 m
5. Run for each angle, export Cl/Cd to CSV
6. Save as `results/naca0012_fluent_Re95k.csv`

## After Getting CFD Results

```bash
# On Windows, integrate with BEMT solver:
python cfd_study/scripts/integrate_cfd_polars.py

# This will:
#  1. Cross-validate OpenFOAM vs Fluent (flag if >5% disagreement)
#  2. Compare BEMT thrust predictions: analytical vs CFD-informed
#  3. Show which airfoil gives best real-world performance
```

## Expected CSV Format

Place results in `cfd_study/results/` with this naming and format:

**Filename:** `{airfoil}_{source}_Re95k.csv`  
e.g. `naca0012_openfoam_Re95k.csv`, `naca0015_fluent_Re95k.csv`

